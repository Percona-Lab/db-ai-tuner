# Web UI review, 2026-10-24

**Method.** An audit of every page type on benchtune.com, logged in, with real data:
- full-page screenshots at 1280 px and 390 px, light and dark mode;
- DOM and overflow measurements, keyboard and tooltip behaviour, resize behaviour;
- a code read of `app.js`, `charts.js`, `app.css`, `status.py` and `main.py`.

**Result.** 82 issues: 17 bugs (P1), 35 clarity problems (P2) and 30 polish items (P3).

**Status.**
- 76 fixed and 4 fixed in part.
- 6 left open:
  - 4 for the reasons at the end;
  - P3-5, which still needs a check of the agent counters;
  - the server-rendered `/status` tooltips.
- Commits 6791df3 (UI) and 3135491 (session auto-close, suite); deployed.

**Validation.** The browser suite `server/tests/ui_suite.py` passes 85 of 85 page checks on the deployed build. It checks for:
- JS and console errors, failed API calls, pages stuck loading, error boxes;
- horizontal scroll at desktop and phone widths;
- invisible chart series;
- tooltips that keyboard users can't reach;
- the features each page must show.

## Polish (P3)

Done:
- Integers without decimals; consistent memory units; "due now".
- Chart titles that match their series.
- Legends of equal height; charts in closed sections drawn when opened; a loading placeholder.
- Env sessions shown 10 at a time; formatted benchmark values; money to 2 decimals.
- Copy buttons on Connect.
- Bar charts redrawn on resize.
- A compact flame graph with a reset crumb and keyboard focus.
- Cheaper optional-column marking; live refresh paused while the pointer is on a chart.
- Larger ⓘ touch targets; ARIA run tabs; row focus highlight.
- Downsampled /status sparklines with min/max and refresh that keeps the scroll position.
- Units on experiment results; studies list without a constant column.
- Parameters search as you type, 100 rows at a time, neutral impact dots.
- Policies linked to Parameters; "saved" confirmation on the learning page.
- Tooltip alignment; full session names (500 characters, ellipsis in tables).
- Theme tokens instead of hard-coded colours.
- A "stalled" badge for sessions on dead hosts (and since 3135491, such sessions close themselves).

## Not done, and why

- **Planner vs rules side by side in studies (P2-21, part):** needs a way for a study to mark paired sessions.
- **Agent's "threads running > connected" on idle hosts (P3-5):** the agent's counters need checking first.
- **Prefilled API key on Connect (P3-13):** only key prefixes are stored.
- **Goal unit on the Notes page (P3-22, part)** and **"N active" on the studies list counting stalled sessions (P3-30, part):** both are small API changes. The second is mostly resolved by sessions now closing themselves.
- **/status ⓘ tooltips** still use `title=`: the page is rendered by the server without app.js.
